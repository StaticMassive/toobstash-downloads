# Toob Stash downloads

Toob Stash is a free app that saves videos from a pasted link and lets you edit them straight away. Made by Static Massive.

## Download

- **Mac** (macOS 11 or later): [ToobStash-mac.dmg](https://github.com/StaticMassive/toobstash-downloads/releases/latest/download/ToobStash-mac.dmg)
- **Windows** (Windows 10 or 11, 64-bit): [ToobStash-windows.exe](https://github.com/StaticMassive/toobstash-downloads/releases/latest/download/ToobStash-windows.exe)

## Install on a Mac

1. Open the downloaded file and drag Toob Stash onto the Applications folder.
2. Open Applications and double-click Toob Stash.
3. The first time only, your Mac says it can't check the app. Click **Done**, open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**, then launch it again.

## Install on Windows

1. Open the downloaded file.
2. The first time, Windows shows "Windows protected your PC". Click **More info**, then **Run anyway**.
3. Follow the installer, then open Toob Stash from the Start menu.
